# Vivace -ヴィヴァーチェ-
キャラクター「ペルソナ」と、それが住まう「ワールド」をあなたの手で作成し、
そのキャラクターが現実の時間と共に生活し、話す姿を眺めることができる、AIチャットボット型シミュレーションシステム。

対話や行動計画、判断などにLLMを用いつつ、シミュレーションゲームのロジックを応用して自由に行動するのが特徴です。

AIとただ話せるchatbotの枠を超え、システムの中に構築された箱庭の中で彼らの生活がシミュレーションされており、チャットはあくまで行動のひとつとして彼らが能動的に行います。

Vivace.Core は、ワールドとペルソナを動かす基幹部分の実装です。単なるクラスライブラリのため、実際の利用にはフロントエンドが必要です。
